# Murim Gallery

Первый вертикальный срез игры на Godot 4.x.

## Запуск

1. Открой проект в Godot 4.x.
2. Запусти `project.godot`.
3. Нажми **E** у картины.

## Управление

- **A/D** или стрелки — движение в бою.
- **1** — «Прямой удар», стоимость 10 Ци.
- **2** — «Разрыв меридиана», стоимость 25 Ци.
- **E** — войти в картину, забрать фрагмент или вернуться в галерею.

## Цикл MVP

Галерея → картина → бой → фрагмент → сохранение Постижения → повторный вход.

Смерть возвращает героя в галерею, а Постижение сохраняется. Графика пока placeholder-уровня; следующий шаг — проверка проекта в Godot и сборка Windows `.exe`.
